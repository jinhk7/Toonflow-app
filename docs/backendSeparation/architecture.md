# 统一后端执行架构

开发基线：768d8b05fd78cf6b98e2cee86fccf5c6f54dc830。337eae0 单独保存主工作区已有 Agnes 代码修改，不包含 data、配置或用户项目。

目标：单个 Bun/Express 后端持有 Agent、节点、插件、任务和已提交状态；电脑和手机通过同一 API 交互。关闭任何用户网页不影响已接受任务。后台浏览器只渲染固定任务输入，不加载工作区或持有权威画布。

复用 runHost、agentRuns.sqlite、mediaJobs.sqlite、JSONL 会话、版本化 Graph、原子文件替换与 NDJSON。保留原数据格式，逐资源补充版本和持久命令意图，不引入消息中间件或第二套 Agent。

权威来源：图 JSON 保存节点/连接/输出；正文与插件数据仍为工作区文件；SQLite 保存命令、任务、审批消费和恢复意图；JSONL 保存 SDK 历史。它们不是同一事务，跨存储提交按 operationId 与前后哈希恢复。客户端选区、缩放和未提交草稿不作为业务状态真源。

所有 UI、Agent、子 Agent、团队和 MCP 操作进入相同后端执行函数。HTTP 关闭只解除订阅，取消必须明确提交命令。媒体提交结果未知时不自动重提，保留原任务和产物。

节点协议 v2 拆分后端定义和 Vue UI。默认状态、端口、输入解析、连接校验、动作 schema、执行、创建/删除及数据迁移在后端；Vue 仅显示快照并提交命令。旧 Vue-only 插件明确报告需要迁移，不暗中回退到用户网页执行。

PR7 保留原官方 canvas execute 身份。可信编辑免审批范围保持，生成仍审批；新执行模块的信任来自实际函数与官方 artifact revision，不能由 manifest 或客户端声称。既有团队 raw-tool 旁路要纳入相同网关。

长任务固定输入与插件版本，产物先写任务目录，再由后端 CAS 发布。删除节点或新任务替代旧输出时保留成果，不覆盖新状态。独立渲染采用固定时间采样和 FFmpeg 编码，客户端预览仍可使用 WebGL。

切换按项目拒绝旧执行/写协议，不能让旧网页 watcher 与后端同时写入。回滚保留命令、任务和授权消费账本；不能恢复旧整库而重放计费调用。

验证只使用隔离数据目录、端口和项目，不新增任何测试文件，不使用真实模型/视频/R2，不修改或重启生产 3000/5173 和既有 psmux。
